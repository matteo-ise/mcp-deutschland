> **Proof of Concept & Infrastructure Blueprint**
> This repository is part of a conceptual infrastructure for Agentic Commerce. It serves as a **Proof of Concept (PoC)** and framework blueprint.

MCP servers bridging German digital infrastructure (XRechnung, DATEV, ELSTER) to AI agents.

## Features
- **XRechnung:** EN 16931 UBL 2.1 XML generator.
- **DATEV:** EXTF format generation and parsing.
- **ELSTER:** USt-VA (VAT return) schema stubs.
- **Tax Utils:** Validations for USt-IdNr, IBAN, and tax numbers.
